The journey

Five weeks, building from Python fundamentals up to a full reconstruction and storytelling pipeline, every step documented honestly, including the parts that failed first.

Week 1 · Foundations
GitHub portfolio, Python, Git, first PR
Set up the reconstruction track's working repo, ran a Structure-from-Motion simulation, and merged the first real pull request.
Week 2 · Research & ML
Footage sourcing, linear regression, method comparison
Sourced and verified multi-angle footage of Badshahi Mosque, Lahore, built linear regression from scratch, and researched COLMAP, NeRF, 3D Gaussian Splatting, and monocular depth as candidate reconstruction methods.
Week 3 · Real 3D Reconstruction
SfM honestly failed, so a monocular reconstruction was built instead
Tested real multi-view Structure-from-Motion on curated photos, it genuinely wasn't viable (12-17 verified matches per pair). Pivoted to a monocular depth heuristic and exported a real, hand-validated 13,375-point .ply reconstruction of the Jaulian monastery ruins at Taxila. Logistic regression on the real Kaggle Titanic dataset followed the same week.
Week 4 · Neural Networks & Storytelling
MNIST classifier, personal storytelling film, team showcase
Trained a Keras neural network to 97.18% test accuracy on real MNIST data, cross-checked against a from-scratch numpy rebuild. Built two short films: one on Team Taxila's heritage work, one a personal story synced to a real recorded voice-over.
Extension Sprints · Verified Make-up Work
Four sprints deepening existing work with real evidence, not new filler
Quantitative point-cloud QA, a live-verified research source log, a 22-case test suite for a system that had zero tests, and a self-audit that caught a real recurring documentation gap and fixed it. Full detail in Extension Sprints below.

3D Reconstruction: Jaulian Monastery, Taxila

The flagship deliverable for this track. Built honestly: real multi-view SfM was tested first and genuinely failed, and that failure is documented, not hidden, before the working monocular approach.

Core Reconstruction
13,375-point validated .ply reconstruction
Hand-built PLY writer, three-way validated (re-parsed, reloaded, cross-checked), now extended with quantitative QA: density, nearest-neighbor outlier detection, and 4-angle rendering.
Full writeup → Download .ply →
Honest limitation: a monocular heuristic depth estimate, not real multi-view triangulation. The SfM test that came first only found 12-17 verified matches per photo pair, a cited heritage-photogrammetry source explains why: reliable multi-view needs about 66% photo overlap, which these 6 photos never had.
ML Visualization & AR
24,091 feature points, AR line overlay
Real Sobel gradient and Harris corner detection on the monastery's cell walls, plus a Hough-line AR-style overlay simulating what a visitor's phone might show live, tightened from a noisy 271 lines down to 25 structural lines.
Full writeup →

Machine Learning, from scratch and verified
